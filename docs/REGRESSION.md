- [x] Логин через IdentityService, редирект на домашнюю страницу по роли
- [x] `RequireAuth` — неавторизованного кидает на `/login`
- [x] `RequireRole` — нет доступа к чужому контуру (`/admin`, `/teacher`, `/student`)

## Контур студента (`STU-015`)

- [x] `/student/courses` — назначенные курсы
- [x] `/student/courses/:courseId` — модули курса
- [x] Модуль → вкладка **Теория**: список → просмотр материала (read-only rich-text + ссылки + документы)

- [x] Практика → **Задания**: пустой стейт (нет файла) → загрузка → «На проверке» → «Принято (оценка N)»

- [x] Практика → **Протоколы**: свои попытки → разбор
- [x] Практика → **Оценка**: итоговая оценка + список условий её получения
