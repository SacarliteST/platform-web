# TD-006 — Совместимость HTML: Quill (legacy) → TipTap

Статус: `Backlog`. Приоритет: P2. Контур: Platform.

## Проблема

Текст теории хранится в `TheoreticalMaterial.Text` как HTML, созданный legacy-редактором
`react-quill` (Quill 1). Новый редактор — `@mantine/tiptap`. Разметка совместима в
основном объёме (заголовки, списки, ссылки, base-форматирование), но краевые случаи
(вложенные списки, инлайновые стили, изображения) надо проверить на реальных данных.

## Что сделать

- Прогнать выборку существующих `Text` через TipTap: рендер read-only + повторное сохранение.
- Зафиксировать список несовместимостей, при необходимости — миграционный проход (sanitize).
- Read-only просмотр (`features/rich-text`) должен корректно показывать старый HTML без правки.

## Готово, когда

Старые материалы читаются и редактируются в TipTap без потери структуры; известные
расхождения задокументированы или устранены.
