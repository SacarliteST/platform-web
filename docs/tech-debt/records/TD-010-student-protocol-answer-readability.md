# TD-010 — Разбор протокола студента показывает сырой ответ вместо читаемого

Статус: `Backlog`. Приоритет: P3. Контур: Student.

## Проблема

В `StudentPracticalPage` вкладка «Протоколы» → «Разбор» столбец «Ваш ответ»
показывает закодированное значение как есть: `["opt-mtlufh5q-15"]` для
MultipleChoice, `opt-mtludrcw-5` для SingleChoice, JSON пар для Match.

`GET /test-results/{testResultId}/protocol` возвращает
`TestProtocolAnswerResponse` без `body` / `type` вопроса, поэтому клиент не может
сопоставить id варианта → текст и переиспользовать `QuestionAnswerView`
(как в разборе преподавателя это тоже плоская таблица, но там ответ короче).

Обнаружено на смоуке `STU-015` (2026-09-03). Функционально корректно:
балл и «верно / неверно» отображаются правильно.

## Что сделать

- Backend: добавить в `TestProtocolAnswerResponse` поля `questionType` и `body`
  (как в `TestQuestionResponse`), либо отдельный эндпоинт разбора с полными
  данными вопроса.
- Frontend: тогда — рендерить разбор через `QuestionAnswerView` (единый вьюер,
  закрывает остаток `STU-008`).
- Как временная мера без бэкенда: для ShortAnswer/SingleChoice показывать хотя бы
  распарсенное скалярное значение вместо JSON-обёртки.

## Готово, когда

В разборе протокола студента ответ показан человекочитаемо (текст вариантов, а не
их идентификаторы).
