# TD-003 — Серверная пагинация и поиск списков

Статус: `Backlog`. Приоритет: P2. Контур: Platform.

## Проблема

Все списочные эндпоинты `Education` возвращают плоские массивы (`IEnumerable<T>`),
без пагинации и серверного поиска. При росте числа курсов / модулей / вопросов /
студентов списки станут тяжёлыми.

## Что сделать

- Не завязывать `entities` на конверт `items` (как в `sql-module-web`) — сейчас данных нет.
- Клиентская пагинация/поиск через Mantine `Pagination` + фильтрация в памяти как временное решение.
- Дождаться `PagedResponse` + query-параметров на бэкенде, затем перевести списки на серверную выборку.

## Зависимость

Backend `Education`: пагинированные ответы и параметры поиска для списков.
