# TD-007 — Минимальная регрессионная защита фронта

Статус: `Backlog`. Приоритет: P2. Контур: Platform.

## Проблема

Фронт-автотестов нет ни в legacy, ни в `sql-module-web` (там это отложенный `STU-020`).
После стабилизации контуров критичную логику стоит покрыть.

## Что сделать (после паритета)

- Unit/component-тесты: нормализаторы `number | string`, payload вопросов 4 типов,
  идемпотентность отправки теста/файла, декодирование сессии и роль-гварды.
- Автоматизированный smoke трёх ролей на тестовом окружении.
- Проверка production build в CI.

## Готово, когда

Критическая бизнес-логика покрыта тестами, smoke прогоняется автоматически.
