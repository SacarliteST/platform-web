# TD-008 — Нет эндпоинта списка курсов/практик для администратора

Статус: `Backlog`. Приоритет: P1. Контур: Admin.

## Проблема

`ADM-011` (назначение студентов на курсы и практики) требует, чтобы администратор
мог выбрать курс/практику. Но в `Education` API списки курсов — `GET /courses/teacher`
(`TeacherOnly`) и `GET /courses/student` (`StudentOnly`); admin-facing списка нет.
`assignable-students` и `PUT .../students` (`AdminOnly`, G-5/G-6) уже есть, но им
нужен известный `courseId` / `practicalId`.

## Варианты

1. **Backend**: `GET /api/v1/courses` (`AdminOnly`) — плоский список всех курсов;
   аналогично `GET /api/v1/practicals` или на курс/модуль. Предпочтительно.
2. **Frontend-stopgap**: экран `ADM-011` с ручным вводом GUID курса/практики.

## Готово, когда

Администратор выбирает курс и практику из списка и назначает студентов без ручного ввода GUID.

## Зависимость

Решение владельца: делать эндпоинт (вариант 1) или временный ввод GUID (вариант 2).
